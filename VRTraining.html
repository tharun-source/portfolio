VR Training Simulator

Wireless Player Data Export | Unity (C#) | Meta Quest 2/3 | Google Apps Script | Google Sheets
About the Project:
As part of a team project, I co-developed the data and menu systems for a Unity VR server room training simulator on Meta Quest. My contribution included a wireless data export module that records player task results and sends them to Google Sheets, so results can be retrieved without connecting the headset to a computer.
Key Features:
  • Records each task's name, completion status, start and end times, and duration
  • Sends player results wirelessly from the headset to Google Sheets through Unity web requests and a Google Apps Script backend
  • Uses Android device IDs to identify headsets and timestamp-based session IDs to keep playthroughs separate
  • Saves a CSV backup on the device when network access is unavailable
